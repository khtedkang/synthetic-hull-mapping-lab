# Changelog

All notable changes to this project are recorded here.

## 1.0.0 — 2026-09-03

- Added deterministic synthetic hull-surface generation.
- Added an explicit starboard-side coverage gap and gap-edge classification.
- Added responsive canvas exploration with pointer and keyboard controls.
- Added accessible point-ID measurement controls and 3D Euclidean distance.
- Added local CSV, JSON, and ASCII PLY downloads.
- Added schema, manifest, sample data, SHA-256 checksums, tests, and boundary scan.
- Added clean-room, AI-assistance, contribution, security, and scope documentation.
