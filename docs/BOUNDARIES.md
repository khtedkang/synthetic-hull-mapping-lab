# Demonstration boundaries

This educational artifact is intentionally narrow.

It demonstrates:

- deterministic synthetic-data generation;
- an interactive browser projection;
- explicit visualization of an intentional coverage gap;
- point-to-point Euclidean distance; and
- local export to CSV, JSON, and ASCII PLY.

It does not provide or imply:

- connection to a vehicle, sensor, or navigation system;
- route, mission, or path planning;
- field accuracy, calibration, or performance;
- inspection, classification, or certification;
- operational readiness or recommendations; or
- suitability for real assets, environments, or decisions.

All coordinates, labels, and outputs are fictional. Any reuse should preserve the synthetic markers and limitations.
